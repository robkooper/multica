This issue is created without a project. Before you start, put it on the current milestone with the github-milestone skill: the open milestone with the earliest due date, or the lowest version when none has a due date. Find or create that milestone's project as the skill describes (Multica only: do not create a GitHub issue for this run or its findings) and move this issue there with `multica issue update <this issue key> --project <project id> --no-start`, so it and every finding you file land on that milestone. If there is no open milestone, use the project "No milestone" instead.
